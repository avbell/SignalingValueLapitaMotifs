Here is data and code to measure the signaling value of Lapita motifs using triad classification tasks. Accompanies the paper in review:

Bell, Adrian Viliami, Gracyn Hinojosa, and David Burley (in review). “Founding Motifs Maintain Signaling Roles Three Thousand Years Later Among the Descendant Population”. 

R script file “BellEtal2026-SI-Rcode.R”. This file contains the primary R script used for the analysis. R script file “CodeBell2019C.R” contains C code called by “BellEtal2026-SI-Rcode.R” used to conduct simulations of the evolutionary model. R data file “TongaUS-TriadData-ForPub.rdata” contains the triad classification data called by “BellEtal2026-SI-Rcode.R” used in the analysis. R data file “AnalysisProgress.rdata” contains the results of the script execution used in the main text. Images “m1.jpeg” through “m8.jpeg” used in the production of the visualizations, called from the primary R script “BellEtal2026-SI-Rcode.R”.

To start,

    Download all files to a single folder
    Open BellEtal2026-SI-Rcode.R
    Set the working directory to the folder within BellEtal2026-SI-Rcode.R
    Install relevant packages as you run through the code.
